Values and variables:
A value is data (numbers, strings, booleans, objects, etc.). A variable is a named container that holds a value.

To assign a value to a variable use the assignment operator =. Examples:
let x = 5;
const name = 'Yahya';
var isActive = true;

You can reassign let and var:
x = 10; // ok for let and var
But const cannot be reassigned:
name = 'Ali'; // Error

//Differences between var, let, and const:
//- var: function-scoped, can be redeclared and //reassigned, hoisted (initialized with undefined).
//- let: block-scoped, can be reassigned but not //redeclared in the same scope, hoisted but not //initialized (temporal dead zone).
//- const: block-scoped, must be initialized at //declaration, cannot be reassigned (but objects/arrays //declared with const can have their contents mutated).
//but what is a block scope?
//A block scope is a section of code enclosed within curly braces {}. Variables declared with let or const inside a block are only accessible within that block and its nested blocks.
//For example, variables declared inside an if statement or a for loop are block-scoped.
//but what is function scope?
//Function scope means that variables declared with var inside a function are only accessible within that function. They cannot be accessed from outside the function.
//For example, if you declare a variable with var inside a function, it cannot be accessed from the global scope or from other functions.
//So the main difference is that var is function-scoped while let and const are block-scoped.
//So in summary, var is function-scoped and can be redeclared, let is block-scoped and cannot be redeclared, and const is block-scoped and cannot be reassigned.

And "var" and "let" each stand for?
They both declare variables. "var" is the older, function-scoped keyword; "let" (introduced in ES6) declares a block-scoped variable.

// operator precedence
// In JavaScript, operator precedence determines the order in which operators are evaluated in expressions.
// For example, in the expression 2 + 3 * 4, the multiplication operator (*) has higher precedence than the addition operator (+),
// so the multiplication is performed first, resulting in 2 + 12, which equals 14.
// precednce in order from highest to lowest including the comparison operators and all other operators:
// 1. Parentheses ()
// 2. Exponentiation **
// 3. Multiplication *, Division /, and Modulus %
// 4. Addition + and Subtraction -
// 5. Comparison operators (==, !=, ===, !==, >, <, >=, <=)
// 6. Logical operators (&&, ||, !)
// 7. Assignment (=)
// In the expression 3 + 4 * 5 > 20, the multiplication is performed first (4 * 5 = 20),
// then the addition (3 + 20 = 23), and finally the comparison (23 > 20), which evaluates to true.
// So the final result of the expression is true.
// In this example, the + and - operators have lower precedence than the typeof operator,
// so the typeof operator is evaluated first to determine the type of the variable or value,
// and then the + and - operators are applied to perform arithmetic operations if needed.

//switch stament
// can be initiated like this:
// switch (expression) {
//   case value1:
//     // code to be executed if expression === value1 
//     break;
//   case value2:
//     // code to be executed if expression === value2
//     break;
//   ...
//   default:
//     // code to be executed if expression doesn't match any case
// }
// where expression can be of any data type
// and the values in each case should be of the same data type as the expression
// the break statement is used to exit the switch statement once a case is matched
// if break is omitted, the code will continue to execute the next cases until a break is encountered or the switch ends
// the default case is optional and will be executed if none of the cases match the expression

//difference between a statment and expression:
// the main difference between a statement and an expression is that an expression produces a value, while a statement performs an action.
// For example, 3 + 4 is an expression because it produces the value 7, while if (true) { console.log("Hello"); } is a statement because it performs the action of logging "Hello" to the console without producing a value.


//template literals expect an expression not a statment

// the conditional ternary operator:
// condition ? expressionIfTrue : expressionIfFalse;
// it is the only operator that takes three operands
// it is used to evaluate a condition and return one of two values based on whether the condition is true or false
// example:
let age = 23;
age >= 18 ? console.log("I like to drink wine 🍷") : console.log("I like to drink water 💧");
